# 🍽 ChipsiRestaurant (Frontend)

Это клиентская часть системы управления рестораном, разработанная на **TypeScript** с использованием **React**.

## 📌 Стек технологий

- **Язык программирования:** [TypeScript](https://www.typescriptlang.org/)
- **Фреймворк:** [React](https://react.dev/) (библиотека для создания пользовательских интерфейсов)
- **Состояние приложения:** [Redux](https://redux.js.org/) (управление глобальным состоянием)
- **Работа с API:** [Axios](https://axios-http.com/) (удобный HTTP-клиент)
- **Роутинг:** [React Router](https://reactrouter.com/) (маршрутизация в SPA)
- **UI-библиотека:** [MUI (Material UI)](https://mui.com/) (готовые UI-компоненты)
