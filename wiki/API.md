# 🔌 API документация

Base URL: `http://localhost:8080/api/v1`

Интерактивная документация доступна по адресу: **http://localhost:8080/docs** (Swagger UI)

---

## 🔑 Аутентификация

API использует **JWT Bearer Token**.

Добавьте заголовок к защищённым запросам:

```
Authorization: Bearer <access_token>
```

### Эндпоинты аутентификации

| Метод | Путь | Описание | Доступ |
|-------|------|----------|--------|
| `POST` | `/auth/signup` | Регистрация нового пользователя | Публичный |
| `POST` | `/auth/login` | Вход в систему | Публичный |
| `POST` | `/auth/refreshToken` | Обновление access token | Публичный |
| `POST` | `/auth/password/forgot` | Запрос сброса пароля | Публичный |
| `POST` | `/auth/password/reset` | Сброс пароля по токену | Публичный |

#### POST `/auth/signup`

```json
{
  "email": "user@example.com",
  "phone": "+79001234567",
  "password": "securepassword",
  "firstName": "Иван",
  "lastName": "Иванов"
}
```

#### POST `/auth/login`

```json
{
  "email": "user@example.com",
  "password": "securepassword"
}
```

**Ответ:**
```json
{
  "accessToken": "eyJ...",
  "refreshToken": "eyJ..."
}
```

## 👤 Защищённые эндпоинты (требуют JWT)

### Пользователь

| Метод | Путь | Описание |
|-------|------|----------|
| `GET` | `/users/me` | Получить профиль текущего пользователя |
| `PUT` | `/users/me` | Обновить профиль |
| `GET` | `/users/me/orders` | История заказов |
| `GET` | `/users/me/reservations` | История бронирований |

### Заказы

| Метод | Путь | Описание |
|-------|------|----------|
| `POST` | `/orders` | Создать заказ |
| `GET` | `/orders/{id}` | Получить статус заказа |
| `GET` | `/orders` | Список заказов пользователя |

**Тело запроса `POST /orders`:**
```json
{
  "items": [
    { "menuItemId": 1, "quantity": 2 }
  ],
  "deliveryAddress": "ул. Примерная, д. 1, кв. 10",
  "bonusesToApply": 100,
  "giftCertificateCode": "CERT-XXXX"
}
```

## 📊 Коды состояний

| Код | Значение |
|-----|----------|
| `200` | Успех |
| `201` | Создано |
| `400` | Неверный запрос |
| `401` | Не авторизован |
| `403` | Доступ запрещён |
| `404` | Не найдено |
| `500` | Внутренняя ошибка сервера |

## 📦 Статусы сущностей

### Статусы заказа (`OrderStatus`)

| Значение | Описание |
|----------|----------|
| `pending` | Ожидает обработки |
| `preparing` | Готовится |
| `delivered` | Доставлен |
| `canceled` | Отменён |

### Статусы бронирования (`ReservationStatus`)

| Значение | Описание |
|----------|----------|
| `pending` | Ожидает подтверждения |
| `confirmed` | Подтверждено |
| `canceled` | Отменено |

### Статусы подарочного сертификата

| Значение | Описание |
|----------|----------|
| `active` | Активен |
| `used` | Использован |
| `expired` | Истёк срок действия |
