## 🚀 Обзор проекта

**Restaurant App** — это монорепозиторий, состоящий из:

- **Backend**: Go (Chi, GORM, PostgreSQL, JWT, MinIO)
- **Frontend**: React 18 + TypeScript (Redux Toolkit, Material-UI, React Router v7)

### Основные возможности

- 🛒 **Система заказов** с отслеживанием статуса доставки
- 🪑 **Бронирование столиков** для зарегистрированных и гостевых пользователей
- 🍱 **Управление меню** (категории, блюда, загрузка изображений)
- 🎁 **Подарочные сертификаты** (отправка, получение, использование)
- 🌟 **Программа лояльности** (начисление и списание бонусов)
- 🎉 **Бронирование мероприятий** (банкеты, кейтеринг)
- 👤 **Аутентификация** с верификацией email и сбросом пароля
- 🗺️ **Интеграция с Яндекс.Картами** для адресов доставки
- 🛡️ **Административная панель** для управления меню и бронированиями
